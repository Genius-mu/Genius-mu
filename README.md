## `$ ls -la projects/`

### ⭐ **Featured Projects**

#### [`NaviLag`](https://navilag.vercel.app) — Campus Navigation & Resources
- **What:** Platform for 25k+ UNILAG students with past papers, timetables, route tracking
- **Stack:** Next.js · TypeScript · Supabase · Framer Motion · Tailwind v4
- **Features:** Faculty/course browsing, Google OAuth, GPS routing, ICS calendar sync, 5k+ downloads
- **Impact:** Replaced fragmented paper/group chat systems; now used campus-wide

#### [`Inkly`](https://inklyma.vercel.app) — Real-Time Collaborative Whiteboard
- **What:** Figma-like multiplayer canvas for instant collaboration
- **Stack:** React 18 · TypeScript · Zupabase Realtime · Canvas API · Zustand
- **Features:** Private by default, invite-by-email, real-time multi-user sync, persistent state
- **Status:** Production-ready; expanding shape tools & export formats

#### [`PHI`](https://github.com/Genius-mu/phi) — Physics Payment Hub Interface
- **What:** Department-wide system for assignment submissions, payment tracking, ledgers
- **Stack:** Next.js · TypeScript · Supabase · Tailwind v4
- **Status:** Week 1 complete; WateryNav component, auth pages, orange theming

#### [`Dropeet`](https://dropeet.app) — Opportunity & Grant Tracker
- **What:** Aggregates African scholarships, grants, and opportunities in one feed
- **Stack:** Next.js 16 · TypeScript · Supabase
- **Collab:** Backend by my sister ([Sumayah](https://github.com/summydev)), Google OAuth flow
- **Status:** MVP live; expanding sources

#### [`Unshelved`](https://unshelved.vercel.app) — Research Rubric Scorer
- **What:** Evaluates Nigerian final-year projects against physics research standards
- **Stack:** Next.js · TypeScript · Tailwind v4 · Gemini API · Supabase
- **Features:** Hallucination-verified scoring with quote extraction

#### [`CodeFlow`](https://codeflow-amg.vercel.app) — GitHub Analytics Dashboard
- **What:** Visualize your GitHub activity, contributions, and insights
- **Stack:** Next.js · TypeScript · GraphQL (optimized API calls from ~129 to ~3)
- **Features:** Interactive charts, contribution trends, performance metrics

#### [`Saim`](https://saim.vercel.app) — AI Sales Agent SaaS
- **What:** Embeddable AI chatbot for sales & customer support
- **Stack:** Next.js · Supabase · Paystack · TypeScript
- **Features:** Customizable personas, live training, analytics, Reveal animations

#### [`AUREA`](https://aurea-ruddy.vercel.app) — Luxury Real Estate Portal
- **What:** Premium property showcase with day/night toggle
- **Stack:** Next.js · React 19 · R3F · GSAP · Lenis smooth scroll
- **Features:** Cinematic animations, WebGL (desktop-only for performance)
